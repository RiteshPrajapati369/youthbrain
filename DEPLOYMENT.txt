# Deployment

This document describes the production deployment pipeline for the YouTh Brain News
portal (https://youthbrain.com.np).

## Production Platform: Cloudflare Workers

The portal is deployed globally to **Cloudflare Workers** using the official
OpenNext adapter (`@opennextjs/cloudflare`) paired with `wrangler`. The edge worker
executes the full Next.js 14 Node.js runtime (Server Components, Route Handlers,
Middleware, Server Actions) via the `nodejs_compat` compatibility flag.

### Deployment Architecture

- **Next.js Compilation:** `npm run build`
- **OpenNext Transformation:** `npx opennextjs-cloudflare build`
- **Cloudflare Edge Deployment:** `npx wrangler deploy`
- **Custom Domain Binding:** `wrangler.jsonc` binds `youthbrain.com.np`

### Build & Deploy Commands

```bash
npm run build
npx opennextjs-cloudflare build
npx wrangler deploy
npm run preview
```

## Managing Cloudflare Secrets via CLI

```bash
echo "re_YOUR_KEY" | npx wrangler secret put RESEND_API_KEY
echo "YOUR_SERVICE_KEY" | npx wrangler secret put SUPABASE_SERVICE_ROLE_KEY
npx wrangler secret list
```

## Custom Domain Configuration (`wrangler.jsonc`)

```json
{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "youth-brain-news",
  "main": ".open-next/worker.js",
  "compatibility_date": "2024-09-23",
  "compatibility_flags": ["nodejs_compat"],
  "assets": {
    "directory": ".open-next/assets",
    "binding": "ASSETS"
  },
  "routes": [
    {
      "pattern": "youthbrain.com.np",
      "custom_domain": true
    },
    {
      "pattern": "www.youthbrain.com.np",
      "custom_domain": true
    }
  ]
}
```
